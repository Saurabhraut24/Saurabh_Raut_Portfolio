## ✨ Key Features

- **⚡ Lightweight & Blazing Fast**: Pure Vanilla HTML5, CSS3, and JavaScript — Zero external libraries or heavy dependencies (< 450 KB total bundle).
- **📱 Fully Responsive**: Custom breakpoints tailored for desktop, tablet, and mobile with a sleek animated slide-down navigation drawer.
- **🪄 Frosted Glassmorphism**: High-end translucent cards with subtle glow borders (`backdrop-filter: blur(18px)`).
- **📂 Dynamic Project Showcase**: Interactive category filtering (*All, Data Analytics, Machine Learning & AI, IoT & Hardware*) rendered via JavaScript.
- **📋 1-Click Clipboard**: Instant copy-to-clipboard functionality for Email and Phone with live feedback.
- **✉️ Netlify Forms Enabled**: Pre-configured with `data-netlify="true"` for automatic message collection in the Netlify Dashboard with direct `mailto:` fallback.
- **📄 Instant Resume Access**: Direct 1-click download and browser preview for `Saurabh_Raut_Resume.pdf`.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Saurabhraut24/Portfolio-Website.git
   cd Portfolio-Website
   ```

2. **Open in browser:**
   - Double-click `index.html`, OR
   - Use VS Code **Live Server** extension: right-click `index.html` -> *"Open with Live Server"*, OR
   - Run a simple local Python server:
     ```bash
     python -m http.server 3000
     ```
     Navigate to `http://localhost:3000`.

## 🌐 Deployment

### Option A: Netlify (Drag & Drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this folder.
3. Your site is live instantly with free SSL!

### Option B: Vercel
1. Push this folder to GitHub.
2. Go to [vercel.com](https://vercel.com) -> **Add New Project** -> Import your GitHub repo.
3. Click **Deploy**.
